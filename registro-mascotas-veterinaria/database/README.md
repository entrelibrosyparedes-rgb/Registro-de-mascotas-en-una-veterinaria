# Base de datos

Base de datos prevista: MySQL.

## Tablas principales

### propietarios

- nombre
- apellido
- telefono
- correo
- direccion

### mascotas
- id
- nombre
- especie
- raza
- sexo
- fecha_nacimiento
- peso
- propietario_id

### vacunas
- id
- nombre
- fecha_aplicacion
- proxima_fecha
- observaciones
- mascota_id
