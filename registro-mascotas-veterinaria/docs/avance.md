# Avance del proyecto

## 1. Problemática

La veterinaria requiere una forma organizada de administrar la información de sus propietarios, mascotas y vacunas. Cuando estos datos se manejan de forma manual o en registros separados, puede ser difícil localizar información rápidamente y llevar un seguimiento adecuado de las vacunas.

## 2. Solución por medio del sistema

Se desarrollará un sistema web para centralizar:

- Propietarios.
- Mascotas.
- Vacunas.
- Fechas de aplicación.
- Próximas fechas de vacunación.

El backend será desarrollado en Java y el frontend utilizará HTML, CSS y JavaScript.
