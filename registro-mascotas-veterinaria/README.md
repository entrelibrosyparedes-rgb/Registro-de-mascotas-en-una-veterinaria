# Registro de Mascotas - Veterinaria

Sistema web para gestionar propietarios, mascotas y vacunas de una veterinaria.

## Avance actual

Este repositorio corresponde al avance inicial del proyecto:

- Problemática

- Backend: Java + Spring Boot
- Java de compilación: 25 (JDK 25 requerido para compilar y ejecutar el backend)
- Frontend: HTML5 + CSS3 + JavaScript

## Problemática

La veterinaria necesita organizar la información de propietarios, mascotas y vacunas. El manejo manual o disperso de estos datos puede dificultar las consultas, provocar duplicidad o pérdida de información y complicar el seguimiento de las próximas vacunas.

## Solución

Se propone desarrollar un sistema web que centralice la información de propietarios, mascotas y vacunas. El sistema permitirá registrar, consultar, editar y eliminar información, además de mantener un historial de vacunación por mascota.
